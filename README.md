# موازنات — متابعة موقف المشاريع

موقع بديل لشيت «موقف المشاريع المتوقفة». نفس الأعمدة ونفس الترتيب ونفس الألوان، وفيه فلتر زي فلتر الإكسيل، وصف إجمالي، وتسجيل دخول بصلاحيات، وسجل لكل تعديل.

**التقنيات:** React + Vite، وSupabase (الدخول وقاعدة البيانات)، والنشر على Vercel.

---

## مكان كل حاجة

| | |
|---|---|
| **Supabase** | نفس مشروع «متابعة المقايسات» (`Mo2ysaaaat`). جداول «موازنات» كلها بتبدأ بـ `mz_`: `mz_projects` و`mz_reviewers` و`mz_members` و`mz_history`. |
| **الحسابات** | نفس حسابات المقايسات (اسم المستخدم + كلمة المرور). الصلاحية على «موازنات» منفصلة في `mz_members`. |
| **GitHub** | الريبو ده. أي تعديل يترفع على `main` بيتنشر تلقائي. |
| **Vercel** | مشروع `mowazanat`، وفيه متغيّرين: `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`. |

### لو احتجت تبني قاعدة البيانات من الأول
في SQL Editor بتاع مشروع المقايسات شغّل `supabase/schema.sql` (مش بيلمس أي جدول من جداول المقايسات).

> بيانات المشاريع نفسها موجودة في Supabase بس، ومش محطوطة في الريبو عشان الريبو عام.

### إضافة مستخدم
1. الحساب بيتعمل ويتوافق عليه من «متابعة المقايسات» زي العادة.
2. من «موازنات» ← الإدارة ← المستخدمين والصلاحيات، اختار له مدير أو محرر أو مشاهد.
3. من عمود «المشاريع اللي يشوفها» اختار الكتيبة أو الكتايب بتاعته. الحساب مش هيشوف ولا هيعدّل غير مشاريعها (والقيد ده في قاعدة البيانات نفسها — `supabase/2_battalion_scope.sql`).

مديرين المقايسات اتعملوا مديرين في «موازنات» تلقائياً أول مرة.

## الصلاحيات
| الصلاحية | تقدر تعمل إيه |
|---|---|
| مدير | كل حاجة، وكمان الحذف وإدارة المراجعين والمستخدمين |
| محرر | إضافة مشاريع وتعديلها وتغيير ✓/✗ |
| مشاهد | عرض وفلترة وتصدير بس |

## الربط بالشيت
| الشيت | الموقع |
|---|---|
| A م | الترتيب (بيتحسب تلقائي زي `=A3+1`) |
| B بيان الاعمال / C القطاع | الاسم والقطاع (ترعة الحمام: القطاع التجريبي، مصرف الحارس، مصرف مريوط) |
| D–N | نفس الأعمدة، وكلها ظاهرة (حتى اللي كانت مخفية في الشيت). تقدر تخفي أي عمود من زرار «الأعمدة» |
| O–R لوحات/موازنة/ذاتي/عقود | ✓ / ✗ / فاضي، وبتتغيّر بضغطة على الخانة |
| S–Y | متوقف على، ما تم اجراؤه، شامل، غير شامل، موقف الموازنة، مكان المشروع (فيه زرار نسخ للمسار)، الملاحظات |
| ألوان الخانات | محفوظة لكل خانة (أخضر / أخضر غامق / برتقالي / أصفر / أحمر) وبتتغيّر من نموذج التعديل |
| صف الاجمالى (123) | بيتحسب لحظياً على اللي ظاهر بعد الفلترة |
| X1:AD1 قائمة المراجعين | صفحة الإدارة |

## تشغيل محلي
```bash
npm install
cp .env.example .env
npm run dev
```
لو شغّلته من غير ملف `.env` هيفتح **وضع تجريبي** فاضي ومتسجّل في المتصفح بس.
